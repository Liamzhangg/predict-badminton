# Training Result Quarantine

`records.csv` excludes the seven normal-status winner/score contradictions identified by the November 16 model/data audit. Original raw source files are preserved. Winners are not flipped or guessed.

Each exclusion pins both the source match ID and canonical fixture signature. A duplicate or renamed fixture alias cannot restore the excluded result. Training and live-history refresh use the same catalog. Records stay excluded until an explicit source review confirms a correction; a later raw-file edit does not silently remove an exclusion.

Other missing scores, unusual formats and valid retirements are not automatically classified as these contradictions. See the [original audit](../../../outputs/audits/model-data-2026-11-16/report.md).
